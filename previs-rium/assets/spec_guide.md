# previz_spec.json 칸 뜻 (쓰면서 보는 안내)

좌표: 미터, +Z 위, 바닥 z=0. 물체 위치 = 바닥 가운데. 사람·물체의 정면 = −Y(정면 카메라 쪽), 사람의 왼쪽 = +X. 예시 = `previz_spec_example.json`.

## meta
- `title` 한 줄 · `version` v1, v2… · `forbidden_colors` **바뀔 대상별 실제 색**(사람 피부·옷, 제품 색, 크게 깔리는 배경)을 글로 — 더미엔 그 색을 안 쓴다(표시). 작은 부분 색은 안 적는다.

## render
- `width`·`height`: 9:16 = 720×1280, 16:9 = 1280×720 · `fps` 24 · `duration` **정수 초, 4~30** · `engine` WORKBENCH(기본).

## palette (종류 → 색 이름)
- 순서표(역할마다 한눈에 다른 색): 주인공 `purple` → 제품 `magenta` → 둘째 인물 `yellow` → 관중·나머지 사람 `deepcyan`(한 색) → 소품 `lime` → `orange`. 물·연기 같은 효과(`effect`)도 순서표에서 아직 안 쓴 다음 색(대개 `orange`). `hotpink`·`violet`·`palecyan`은 역할 구분에 쓰지 않는다(마젠타·보라·시안과 헷갈림). 사람은 `palette`에 id로 색을 적은 사람만 따로 칠해지고, 안 적은 사람은 첫 사람만 `purple`, 나머지는 전부 관중 색(`deepcyan`, 바꾸려면 `"crowd"` 키). 분홍 제품이면 마젠타 대신 순서표의 다음 색. 사람을 id로 따로 칠하려면 `palette`에 id를 키로 적는다(예: `"hero": "purple", "defender": "yellow", "crowd_01": "deepcyan"`).
- 바뀔 대상과 비슷한 색 ✕(파랑≈얼음·하늘, 갈색≈나무, 초록≈잔디, 주황≈피부). 사람을 회색으로 ✕.

## world
- `floor: true` · `set`: 회색 상자들(벽·가구·랜드마크). `{"id","size":[폭X,깊이Y,높이Z],"pos":[x,y,z],"rot":도}`.
- 카메라가 도는 컷엔 **비대칭 랜드마크** 하나(`"type":"landmark"` 기둥) — 사방이 같으면 방위를 잃는다.
- 세트는 그 장소에 있을 법한 모양으로(창밖 회색 상자 → 창고로 읽힘). 원본에 있는 세트·소품은 빼지 않는다(사용자가 빼라고 한 것만) — 모양이 헷갈리면 실제 크기의 단순한 상자로 줄인다.

## objects
- `kind`: `person`(3부품 + 허리 힌지 자동) · `product` · `prop` · `effect`(물·연기 자리) · `animal` · `vehicle`
- `shape`(사람 외): `box` 기본 · `dirbox`(돌 때 어느 면인지 읽혀야 함 — 정면 = −Y) · `prism`(`sides` 각기둥) · `lump`(덩어리) · `plane`
- `size` 실제 치수 m [폭, 깊이, 높이] — 결과는 상자보다 1.1~1.6배 크게 나오니 **실제 크기로**. 화면에서 너무 작으면(높이 4%) 사라진다 — 주인공 크기는 원본 그대로 두고, 원본에서 35%보다 작아도 키우지 말고 작업기록에 「작게 나와 치환이 약할 수 있음」만 적는다(키우는 건 사용자가 말할 때만).
- `height`(사람, m). 아이는 `child: true`.
- `facing_marker`(사람만, 방향 표시): 머리 앞 쐐기 + 가슴 앞 세로 띠(같은 색의 어두운 단)로 앞면을 읽히게 한다. `"auto"`(기본 — `rot` 키 폭이 45° 이상이면 켬) · `true`/`"both"`(돌기는 작아도 누구 쪽을 향하는지가 중요할 때) · `"chest"`(얼굴에 제품을 쓰는 사람 — 쐐기가 제품 상자와 겹침. auto면 얼굴 앞에 `kind: product`가 0.25초 넘게 오는 사람을 스크립트가 저절로 chest로 내리고 `[점검]` 줄로 알림) · `"head"` · `false`. 켜진 사람은 렌더 출력 `[방향 표시] <id>(쐐기+띠 | 띠만 | 쐐기만)`·report.json `qc.facing_marker`에 나오고, 넘기기 색 키에 나온 종류의 구절로 선언한다(`prompt_canon.md` §0-B).
- 렌더 출력 `[몸 방향]`(report.json `qc.facing_to_lens`): 관중 색이 아닌 사람·방향 표시가 켜진 사람마다 렌즈 기준 몸 방향을 0.5초마다(0° 정면 · 90° 옆 · 180° 등, 오·왼 = 몸 앞이 향하는 화면 쪽). 넘기기 글의 몸 각도는 이 값을 따른다 — 각도를 바꾸려면 `rot`부터.
- `keys[]`: `t`(초) · `pos` · `rot`(도, 위에서 봐 반시계 +) · `rot_x`(앞뒤 기울기, 눕기 90) · `bend`(허리: + 앞으로 숙임 / − 젖힘, 큰 자세는 이걸로) · `scale` · `visible` · `ease`(`inout` 기본·`linear`·`in`·`out`=감속 도착)
- `follow`: 다른 물체에 붙기(손에 든 제품 등). `offset`은 사람 허리 기준(앞 = −Y). **몸 밖에 두기**(머리 반폭 ≈ 0.07H, 어깨 반폭 ≈ 0.13H). `until` 뒤엔 `keys`가 이어받는다 — 그 시각 key 위치를 손 위치와 같게.
- `pivot`: 도는 중심(뚜껑 열기 = 뒤쪽 아래 모서리).
- 제품은 **돌리지 않고 카메라가 돈다**(제품이 돌면 모르는 뒷면을 지어냄).
- 프리비즈로 못 나르는 것(앉기·눕기·팔 뻗기·손가락·표정·질감·빛) → 위치·높이만 맞추고 **글로 보낼 목록**에.

## 원본 그대로 옮기기(관중·행인 포함)
- 사람마다 물체 하나씩, 자리(`pos`)는 원본 프레임(`01_프레임/cuts_full/`)에서 읽은 화면 위치를 미터로 옮긴 값. **반복문으로 같은 간격·같은 줄 높이로 찍어 내지 않는다** — 원본이 무리·빈틈·비대칭이면 그대로, 원본이 균일하면 균일하게.
- 앉은 사람은 낮게(`height` 1.1~1.2 또는 `bend`), 서 있는 사람은 키를 조금씩 다르게(1.55~1.85), 방향(`rot`)은 원본에서 보는 쪽으로.
- 미터 좌표는 짐작이니, 빠른 렌더 뒤 `compare.mp4` 프레임을 원본과 나란히 보고 자리를 맞춰 고친다.
- 관중 색은 `palette`의 `"crowd"` 키 하나로(사람마다 다른 hex ✕).

## cuts
- 각 컷 `{"id","start","end","camera":{...}}`. 앞 컷 `end` = 다음 `start`. 컷 = 1프레임 도약(하드컷). 컷 경계·길이는 원본 컷 그대로(원본에 없는 컷을 더하거나 원본 컷을 합치지 않는다).
- `camera.move` 한국어 메모(스크립트는 안 읽음, 사람이 읽음) · `target` 물체 id 또는 좌표 · `look_offset` 바라볼 높이(가슴 1.2·얼굴 1.55·제품 중심) · `follow` 대상 따라감(기본 true)
- 방위·거리·높이·렌즈: `az`(0 = 대상 정면, + = 대상의 오른쪽) · `dist`(m) · `h`(m) · `lens`(mm; 21~28 활기 / 32~40 제품+손 / 45~60 중립 / 70~105 히어로·접사)
- 두 줄 표 `from`/`to` + `ease`, 또는 여러 줄 `keys`(단조 보간). 원테이크로 여러 대상을 옮겨 다니면 `target` 없이 `pos`·`look` 좌표 키로.
- 손맛 = 흔들림이 아니라 **속도 곡선**(가감속·도착 뒤 정착은 키 간격·ease로). 흔들림은 넣지 않는다. 속도 램프(빠름 → 슬로 → 감속 정지)도 키 간격으로.
- 접사는 한 곡선으로(급 줌·중간 멈춤 ✕). 제품 디테일 접사는 약 1초 머물고 화면의 12~15%는 돼야 클로즈업으로 읽힌다.
- 마지막 컷: 카메라가 **끝까지 진행**. 멈추는 엔딩만 `hold_end`(초) + `hold_reason`.
- 점검 자동(렌더 출력 `[점검]` 줄 = report.json `qc.warnings`): 화면 점유 75% 이하 · 사람 표면과 카메라 0.8m 이상 · 마지막 프레임 정지 ✕ · 정수 초·해상도·fps. 원본이 원래 그런 컷이면 고치지 말고 이유를 적는다.

## 수정 판 — 말한 부위만
- 직전 판 명세를 그대로 복사해 `version`만 올리고, 요청한 물체·시간대만 고친다. 다른 사람의 `pos`·`rot`·`bend`, 카메라(`cuts`), 세트는 손대지 않는다. 키를 다시 찍어야 하면(예: 매 프레임 키로 바꿈) 값은 직전 판과 같게.
- 손·손가락·표정처럼 더미가 못 나르는 요청은 명세가 아니라 큐시트 `to_text`·`body_language`로.
- 렌더: `previz.py <새 spec> --out vN --ref <원본> --prev v<N-1> [--quick]` → `[직전 판 대비]` 줄 + `sheet_compare_prev.jpg`([원본 | 직전 | 이번])를 이미지로 확인. 말한 것 말고 바뀐 줄이 있으면 되돌린다. 명세 두 개만 비교할 땐 `python3 scripts/spec_diff.py <직전 spec> <새 spec>`.

## 자주 하는 수정 → spec 바꾸는 곳
| 사용자 말 | 바꾸는 곳 |
|---|---|
| 마지막 컷을 제품 접사로 | 마지막 cut `camera.target: "product"`, `dist` 0.6~0.8, `lens` 50~85, 끝까지 아주 느린 푸시인 |
| 더 천천히 / 더 빨리 | 키 `t` 간격 늘리기/줄이기, `ease` |
| 사람이 더 크게 | `dist` 줄이기(점유 75% 안) 또는 `lens` 올리기 |
| 왼쪽에서 들어오게 | 첫 key `pos`의 x를 +(사람 왼쪽 = +X)… 카메라 기준이면 `az`로 확인 |
| 제품을 손에서 테이블로 | `follow.until` 시각 + 그 시각 `keys` 위치를 손 위치와 같게 → 다음 key 테이블 위 |
| 더미를 더 자세히 | **안 한다**(빼기). 큰 자세만 `bend`·`rot`로 |
| 이 동작을 저 동작으로(예: 손 제스처 → 선글라스 꺼내 쥐기) | 몸 키는 **그대로**. 새 물건이 있으면 실제 크기 상자 + `follow`, 손동작은 큐시트 `to_text`, 큐시트 `meta.user_changes`에 바꾼 부위·**그 동작이 나오는 모든 시간대** 기록(프롬프트엔 새 동작만 — 원본 동작 이름 ✕) |
| 몸을 더/덜 돌려 · 누구 쪽을 보게 · 「살짝 측면으로」 | 그 시간대 `rot`만(글로만 쓰지 않는다). `--prev`로 확인하고 새 `[몸 방향]` 값으로 넘기기 글을 쓴다. 방향 표시가 켜졌는지 `[방향 표시]` 줄로 확인(안 켜지면 `facing_marker: true`) |
